# Avokaido Starter

A mobile app for iOS and Android, generated by Avokaido.

## Run it

```bash
flutter pub get
flutter run -d iphone     # iOS Simulator
flutter run -d android    # Android emulator
```

The native `android/` and `ios/` projects are part of this repository.

## How it ships

Every push to `main` runs three workflows:

- **flutter-ci** — formatting, analysis, tests and a debug Android build.
- **Release (Android)** — a signed release app bundle, kept as a workflow
  artifact, and uploaded to Google Play internal testing when the workspace
  has Play credentials. A new app's first bundle has to be uploaded by hand
  in Play Console.
- **Release (iOS)** — signed with fastlane match and uploaded to TestFlight
  when the workspace has an App Store Connect key; otherwise an unsigned
  `Runner.app` artifact. A new app's App Store Connect record has to be
  created by hand once.

The release workflows, `fastlane/`, the `Gemfile` and
`android/app/build.gradle.kts` were written when the project was created and
are kept as they are by Avokaido's agent.
